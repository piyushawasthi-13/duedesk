# DueDesk

Rent & fee dashboard for PGs, libraries, gyms and tuition centres — with online member payments.

- **Owner dashboard:** https://piyushawasthi-13.github.io/duedesk/
- **Member pay page:** `pay.html?t=<link token>` (owners share it from the app)

Backend: Supabase project `zxdeuotgjvbpoeptldnv` (database in `supabase/schema.sql`, Edge Function in `supabase/functions/duedesk`).
The website is plain static files — any change pushed to `main` goes live on GitHub Pages.
